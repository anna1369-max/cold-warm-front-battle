# 冷暖氣團對抗戰

一個結合氣象知識的雙人(玩家 vs 電腦)卡牌對抗小遊戲。把鋒面推到對手的基地,同時學習冷暖氣團、鋒面、台灣在地天氣現象的原理。

## 線上遊玩

啟用 GitHub Pages 後,網址會是:

```
https://<你的帳號>.github.io/<repository 名稱>/
```

## 本機遊玩

直接用瀏覽器開啟 `index.html` 即可,不需要安裝任何套件或伺服器。

## 玩法簡介

- 選擇冷氣團或暖氣團,並選擇氣團出身(決定起始氣壓與水氣)與開局季節。
- 共 12 回合,每 3 回合換一季,每回合有 3 點能量可以出戰術卡。
- 目標是把鋒面推到對手的基地:冷氣團基地在最北的華北,暖氣團基地在最南的南海。
- 每張卡背後都附有氣象原理說明,回合結束的天氣結算也會反映對應的知識點。

## 技術

單一自包含的 `index.html`,純 HTML / CSS / JavaScript,沒有任何建置流程或外部依賴(僅使用 Google Fonts)。
